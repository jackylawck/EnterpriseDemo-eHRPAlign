「設計階段保護私隱・多模態 AI 驅動之入職文檔標準化與合規對齊引擎」

📌 專案摘要 (Executive Summary)

eHRP Align 是針對企業入職檔案多源紛繁、影印掃描件品質不一及數據審計需求自主研發之智能化資料對齊系統。

本專案結合多模態 Vision AI 光學認知引擎與指向性事實來源核對技術（Source Grounding），自動解構新員工合約、身份證明、銀行戶口、申請表及專業證書合集。系統落實純 Session 記憶體運算與零數據留存（Zero Data Retention），並精準輸出 eHRP 結構化 JSON Payload，徹底杜絕傳統人工鍵入疏漏與資安外洩風險。

🏛️ 流程生命週期與治理閉環 (Workflow Lifecycle)

傳統 HR 建檔易受多份文件資料衝突與模糊辨識干擾。本系統透過五重管治閉環，達成 100% 可追溯的人機協同（Human-in-the-Loop）：

第一步・攝取
多源文件合集上傳
支援多頁 PDF/掃描件，PyMuPDF 自動轉高解析記憶體圖像。
第二步・對齊
指向性單一來源核對
依法律效力位階，精確鎖定合約第 3 條、身份證及申請表。
第三步・防虛
零幻覺安全過濾
不確定或模糊欄位強制留空（""），嚴禁模型憑空揣測。
第四步・清洗
欄位標準化映射
部門代碼自動轉化為 HQ/ENG/OPS 等標準代碼，拆分中文姓名。
第五步・閉環
人工複核與 Payload 匯出
HR 專員確認數據，一鍵匯出 JSON 供 Chrome Extension 自動填表。

📋 資料來源權重與指向性對照表 (Source Grounding Matrix)

資料維度 目標欄位 法定單一事實來源 (Ground Truth) 提取與標準化規則
僱傭與職級 薪金、Rank、Grade、支薪點 月薪僱傭合約第 3 條 嚴格鎖定「每月底薪、支薪點、級別、職級」條款提煉，杜絕手誤。
法定身份 英文姓名、身份證號碼 法定居民身份證明文件副本 以證件全大寫字母為唯一準則，自動校驗括號校驗碼。
中文姓名 中文姓氏、中文名字 身份證明 / 申請表 啟動演算法自動拆分姓氏與名字，避免整組擠入名字欄位。
結算戶口 銀行名稱、帳號號碼 銀行卡 / 提款卡影印本 比對官方銀行字典，自動校正拼音錯字（如 YANG SENG 矯正為 HANG SENG）。
聯絡與住址 手提電話、住宅住址 職位申請表 (Demo-Form-001) 以親筆填報資料為準，輔以住址證明文件交叉校驗。
資歷與緊急人 緊急聯絡人、證書、履歷 申請表 / 專業證書影印本 提煉急救證、各類安全及技能證書紀錄，整理為標準結構陣列。

⚙️ 技術亮點與安全防禦 (Technical & Security Architecture)

1. 零數據留存架構 (Zero-Data-Retention)

貫徹 Privacy by Design 原則。上傳之影印件與解析內容僅存在於 Session 記憶體中，關閉或重新整理網頁即觸發物理銷毀。

2. 雙軌 Vision 多模態 OCR 管線

整合 PyMuPDF 高階向量解析與視覺渲染，自動將多頁影印掃描本編碼為優化記憶體串流，突破傳統 OCR 無法解析劣質影印本之瓶頸。

3. ISO/IEC 42001 (AIMS) 管治對齊

嚴格限制模型推理邊界，實施「未明確即留空」防虛假機制，並維持 100% Human-in-the-Loop 人工複核要求。

4. 企業憑證安全隔離 (ISMS A.8.12)

API 金鑰以後端環境變數與 Secrets 加密封裝，前端 UI 零暴露，原始程式碼庫維持 100% 零硬編碼個人可識別資訊 (PII)。
